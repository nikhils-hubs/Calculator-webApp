# 🧮 Calculator App

A simple and responsive Calculator App built using **HTML**, **CSS**, and **JavaScript**.  
This calculator can perform basic arithmetic operations with a clean and user-friendly interface.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear/Delete functionality
- 📱 Responsive design
- ⚡ Fast and lightweight

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
